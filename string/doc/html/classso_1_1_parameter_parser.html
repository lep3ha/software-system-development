Подробное описание

Класс для разбора аргументов запуска программы.

Класс содержит число аргументов запуска и их строковые значения. Основной метод класса getParameters выполняет разбор аргументов при помощи функции getopt и формирование параметров моделирования в виде объекта класса Parameters.
